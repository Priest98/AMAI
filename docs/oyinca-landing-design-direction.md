# Oyinca landing design direction

Oyinca combines editorial restraint with a tactile operating-system interface. Deep navy provides confidence; mineral blue signals intelligence; warm ivory keeps the product human; apricot appears only as a moment of attention. The recurring open orbit represents work continuously moving around the customer while leaving them in control.

Typography pairs Playfair Display for decisive editorial statements with Inter for product clarity. Layouts use asymmetric negative space and thin technical rules. Cards only appear when they represent real product objects or decisions. Depth is soft and physical, never glossy decoration.

The page moves from the brand promise and manager preview, through the repeated work Oyinca removes, into one visual content loop from source to approval, followed by plans, trust answers and a focused free-start invitation. Literal foliage, dense charts, fake metrics, ornamental controls and repeated floating panels from the references were deliberately excluded.

## Humanoid hero asset

The cinematic Oyinca humanoid was generated with the built-in image-generation tool as an original project asset, using the supplied screenshot only as inspiration for the welcoming gesture and large-scale composition. The final prompt requested a calm, human social media manager with direct eye contact, an extended hand, restrained orbital intelligence, deep navy atmosphere, warm ivory clothing and apricot lighting. It explicitly excluded copied identity, logos, interface text, chatbot panels, statistics, cyberpunk neon and generic robot armour.
