# Design References and Synthesis

Research reviewed 2026-09-09 from the public `VoltAgent/awesome-design-md` design library.

| Reference | Selected principles | Rejected for Oyinca |
|---|---|---|
| [Runway](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/runwayml/DESIGN.md) | full-bleed media, UI retreat, editorial type, minimal shadow | an image-first product workspace that hides operational state |
| [Apple](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md) | whitespace, product focus, restrained action color, clear hierarchy | imitation hardware chrome and excessive empty product space |
| [Superhuman](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/superhuman/DESIGN.md) | fast scanning, focused CTA, calm canvases, tight type | speed theater, inaccessible shortcut dependence, decorative density |
| [Stripe](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/stripe/DESIGN.md) | legible complexity, clean forms, tabular data, strong CTA hierarchy | a generic blue SaaS template or dense developer-documentation tone |
| [Ferrari](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/ferrari/DESIGN.md) | scarce accent, confident imagery, hairlines, disciplined spacing | automotive luxury cues, aggressive red, or spectacle in work screens |

The Oyinca result is original: warm editorial acquisition, gunmetal cinematic depth, steel interaction cues, and crisp operational surfaces. The references are decision inputs, not component templates.
