# Dashboard design context

Use `docs/design/OYINCA-DESIGN.md` and `docs/design/COMPONENTS.md`. The dashboard is a calm working environment: opaque semantic surfaces, product typography, tabular data, immediate feedback, and one clear next action. Search `components/ui` before adding controls. Apply `exec-card-interactive` only when the complete card acts; static cards do not lift.

Show brand, platform, time, approval, processing, failure, and stale-data context wherever they change a decision. Preserve drafts and entered values across recoverable errors. Use native scroll, respect reduced motion, keep touch targets at least 44px, and verify task order at 360px before optimizing the desktop composition.
