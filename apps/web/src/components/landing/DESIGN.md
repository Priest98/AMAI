# Landing design context

Use `docs/design/OYINCA-DESIGN.md` as the canonical system. This folder owns Oyinca's cinematic acquisition mode: one dominant visual, minimal copy, editorial display type, dynamic-island navigation, and one primary CTA per viewport band. Keep headline meaning and primary actions in HTML and available without animation. Scope GSAP and Lenis here, clean them up on unmount, and provide a complete reduced-motion state.

Do not import landing treatments into dashboard components. Glass, glow, oversized display text, parallax, and full-bleed media are deliberate story tools rather than default decoration.
