# Agent Bootstrap Prompt

Use the `premium-ui-ux` skill for all meaningful frontend design,
redesign, landing-page, dashboard, SaaS UI, mobile UI, component-system,
and interaction-design work.

Before editing: 1. inspect the existing codebase and design system; 2.
identify the primary user task and business objective; 3. select a
coherent visual direction; 4. consult only the relevant resources in
`references/resource-map.md`.

During implementation: - preserve working product behavior; - prefer
existing components and tokens; - make mobile/responsive behavior
intentional; - implement all important UI states; - keep accessibility
and performance as release gates; - use animation selectively; - avoid
generic AI/vibe-coded visual defaults.

After implementation: - run the application; - inspect the result
visually at mobile and desktop sizes; - check console/runtime errors and
key interaction states; - iterate on spacing, hierarchy, typography and
responsiveness before declaring completion.

For specialized tasks, route through
`references/specialized-skill-routing.md`; never load every companion
skill indiscriminately.
